# ✍️ Handwritten Digit Recognition

A Machine Learning project that recognizes handwritten digits (0–9) from images using a trained neural network model. The system takes an image of a handwritten digit as input and predicts the corresponding numerical value.

## 📌 Project Overview

Handwritten Digit Recognition is one of the most popular beginner projects in Machine Learning and Deep Learning. This project is trained using the MNIST dataset, which contains thousands of handwritten digit images.

The model learns patterns from the training data and can accurately classify handwritten digits into one of the ten classes (0–9).

## 🚀 Features

- Recognizes handwritten digits from images
- Trained on the MNIST dataset
- High prediction accuracy
- Image preprocessing and normalization
- User-friendly prediction interface
- Supports digits from 0 to 9

## 📊 Dataset

This project uses the **MNIST (Modified National Institute of Standards and Technology)** dataset.

Dataset Details:
- 70,000 handwritten digit images
- 60,000 training images
- 10,000 testing images
- Image size: 28 × 28 pixels
- Classes: 10 (Digits 0–9)

🧠 Model Training

Steps involved:

Load MNIST dataset
Preprocess images
Normalize pixel values
Build Neural Network model
Train the model
Evaluate performance
Predict handwritten digits
📈 Results
Training Accuracy: ~98%+
Testing Accuracy: ~97%–99%

(Accuracy may vary depending on model architecture and hyperparameters.)
